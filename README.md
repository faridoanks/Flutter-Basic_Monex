# Monex - Expense Management App 📱💾

Aplikasi manajemen keuangan pribadi berbasis **Flutter** yang dirancang untuk mencatat pemasukan dan pengeluaran secara praktis. Proyek ini dikembangkan secara aktif menggunakan arsitektur modern sebagai bagian dari **Portofolio Magang untuk Pansus Studio**.

> ⚠️ **Status Proyek:** *Under Development* (Sudah Menyelesaikan Tahap Dashboard/Overview)

---

## 🛠️ Tech Stack & State Management
* **Framework:** Flutter (Dart)
* **State Management:** Riverpod (Proactive & Scalable State)
* **Backend & Database:** Firebase (Authentication & Cloud Firestore)

## 🚀 Progress Pengembangan (Roadmap)
Tim Pansus Studio dapat memantau perkembangan fitur dan alur implementasi kode melalui checklist berikut:
- [x] Perancangan UI/UX Lengkap (Onboarding hingga Notifikasi)

- [x] Halaman Dashboard / Overview (Selesai Slicing & Integrasi State Riverpod)
- [ ] Fitur Tabungan / Savings (Rencana Selanjutnya)
